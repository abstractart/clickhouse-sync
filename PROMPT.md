# Цель проекта
Скрипт который позволит переносить данные между дисками ClickHouse кластера (с шардами и репликами внутри шардов)

# Требования к реализации
Входные данные:
- username
- password
- hostname
- database
- table
- partition
- destination_disk

Используя их скрипт делает 
- Запрос к системной таблице чтобы получить имена всех узлов кластера.
- В цикле идет перебор узлов и на каждом мы запускаем операцию ALTER TABLE MOVE PARTITION TO DISK

Пожелания к реализации
- Golang with stdlib
- Clickhouse клиент не нужен, используй HTTPS соединение

# Тестирование и локальная инфраструктура
- нужно добавить через docker compose кластер ClickHouse с шардами и репликами +  seaweedfs для object_storage диска
- В кластере должна быть таблица (шардируемая и реплицируемая)
- В кластере должно быть подключено несколько disks - local, object_storage.
- Данные переносим из Object Storage диска на локальный
